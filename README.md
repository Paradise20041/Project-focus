# Project-Focus 

Focus app: Pomodoro, music, noises, notes, To-Do, and Kanban.

## Installation
1. Unzip the archive
2. Run `Project-focus.exe`

## How to add music
Place `.mp3`, `.ogg`, or `.wav` files in the `music` folder next to `.exe`.

## Supported languages
- Русский
- English
- 中文
- 日本語
- Español
